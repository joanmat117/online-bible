# Online Bible

[![Next.js](https://img.shields.io/badge/Next.js-14-black?style=flat&logo=next.js)](https://nextjs.org/) [![React](https://img.shields.io/badge/React-18-blue?logo=react)](https://reactjs.org/)[![Redux](https://img.shields.io/badge/Redux-Toolkit-purple?logo=redux)](https://redux-toolkit.js.org/)[![Material-UI](https://img.shields.io/badge/Material--UI-5-blue?logo=mui)](https://mui.com/)[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)[![Vercel](https://img.shields.io/badge/Deployed%20on-Vercel-black?logo=vercel)](https://online-bible.vercel.app)

Una aplicación web moderna para leer la Biblia de forma fácil y sencilla. Desarrollada con React, Next.js y Material-UI.

**Demo en vivo**: [https://online-bible.vercel.app](https://online-bible.vercel.app)

![Online Bible Preview](https://iili.io/f2QFsVI.jpg)

## Características

- **📖 Lectura sencilla**: Navegación intuitiva por libros, capítulos y versículos
- **🎯 Versículo aleatorio**: Inspírate con un versículo diferente cada día en la página de inicio
- **💾 Progreso guardado**: La app recuerda automáticamente tu último capítulo leído
- **⭐ Versículos favoritos**: Guarda tus versículos preferidos para acceder rápidamente
- **📝 Notas personales**: Agrega notas personales a cualquier versículo
- **🌙 Modo oscuro**: Interfaz adaptable con tema claro y oscuro
- **📱 Diseño responsive**: Optimizado para móviles, tablets y desktop

## 🛠️ Tecnologías

- **Frontend**: React 18, Next.js 15
- **Gestión de estado**: Redux Toolkit con Context API
- **UI Framework**: Material-UI (MUI) v5
- **Despliegue**: Vercel
- **Iconos**: Solar Icons

## 🚀 Instalación

Sigue estos pasos para ejecutar el proyecto localmente:

1. **Clona el repositorio**:
   ```bash
   git clone https://github.com/tu-usuario/online-bible.git
   cd online-bible
   ```

2. **Instala las dependencias**:
   ```bash
   pnpm install
   # o
   yarn install
   ```

3. **Ejecuta el servidor de desarrollo**:
   ```bash
   pnpm run dev
   # o
   yarn dev
   ```

4. **Abre tu navegador** en [http://localhost:3000](http://localhost:3000)

## 📖 Cómo usar

1. **Lectura**: Navega entre libros y capítulos usando el menú en la barra inferior.
2. **Progreso automático**: Tu última posición se guarda automáticamente
3. **Guardar versículos**: Haz clic en el icono del marcador para guardar versículos.
4. **Agregar notas**: Escribe en el input de notas para agregar una nota al versículo.
5. **Modo oscuro**: Cambia entre temas en la configuración
